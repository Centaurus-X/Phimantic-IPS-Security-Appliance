# Phimantic-IPS-Security-Appliance

## Code of Conduct

## Our standard

This project expects professional, respectful and security-conscious collaboration. Contributors should focus on technical facts, reproducible evidence and constructive improvements.

Examples of welcome behavior:

- report problems with clear logs, versions and reproduction steps;
- discuss trade-offs respectfully;
- review patches against the documented security invariants;
- help new users deploy and test safely;
- credit upstream projects and contributors.

Unacceptable behavior includes harassment, insults, threats, discrimination, deliberate disruption, disclosure of private information, or public posting of unresolved security vulnerabilities.

## Security-sensitive discussions

Do not publish exploit details, bypass techniques or operational secrets in public issues. Use the security reporting process in [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may remove content, close issues, restrict participation or block accounts that violate this code of conduct. Enforcement should be proportionate, documented and focused on keeping the project safe and useful.

## Scope

This code applies to repository discussions, issues, pull requests, documentation, chat channels and any project-related event or communication channel.
